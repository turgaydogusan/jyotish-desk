### Astrolojik tanımlar (kaynak: BPHS böl. 3, R. Santhanam çevirisi)

| Graha | Yücelme (derin) | Düşüş | Moolatrikona `[başlangıç, bitiş)` | Kendi burcu |
|---|---|---|---|---|
| Güneş | Koç 10° | Terazi 10° | Aslan 0–20° | Aslan |
| Ay | Boğa 3° | Akrep 3° | Boğa 3–30° | Yengeç |
| Mars | Oğlak 28° | Yengeç 28° | Koç 0–12° | Koç, Akrep |
| Merkür | Başak 15° | Balık 15° | Başak 15–20° | İkizler, Başak |
| Jüpiter | Yengeç 5° | Oğlak 5° | Yay 0–10° | Yay, Balık |
| Venüs | Balık 27° | Başak 27° | Terazi 0–15° | Boğa, Terazi |
| Satürn | Terazi 20° | Koç 20° | Kova 0–20° | Oğlak, Kova |

- **Yücelme ve düşüş burç bazındadır**, derin nokta yalnızca bilgi için saklanır. Bir istisna var: Ay'ın ve Merkür'ün yücelme burcu moolatrikona burçlarıyla aynıdır. Bu yüzden yücelme yalnızca moolatrikona aralığından önceki derecelerde geçerlidir: Ay Boğa 0–3°, Merkür Başak 0–15°.
- **Kontrol sırası:** düğüm → `None`, sonra yücelme, düşüş, moolatrikona, kendi burcu. Bunlardan hiçbiri değilse burç lorduna göre panchadha maitri uygulanır.
- **Doğal dostluk (naisargika):**
  - Güneş: dost Ay, Mars, Jüpiter; nötr Merkür; düşman Venüs, Satürn.
  - Ay: dost Güneş, Merkür; nötr Mars, Jüpiter, Venüs, Satürn; düşmanı yok.
  - Mars: dost Güneş, Ay, Jüpiter; nötr Venüs, Satürn; düşman Merkür.
  - Merkür: dost Güneş, Venüs; nötr Mars, Jüpiter, Satürn; düşman Ay.
  - Jüpiter: dost Güneş, Ay, Mars; nötr Satürn; düşman Merkür, Venüs.
  - Venüs: dost Merkür, Satürn; nötr Mars, Jüpiter; düşman Güneş, Ay.
  - Satürn: dost Merkür, Venüs; nötr Jüpiter; düşman Güneş, Ay, Mars.
- **Geçici dostluk (tatkalika):** Lord, grahanın burcundan sayınca 2, 3, 4, 10, 11 veya 12. burçtaysa dosttur. 1, 5, 6, 7, 8 ve 9. burçlardaysa düşmandır.
- **Panchadha (birleşik) dostluk:**
  - Dost + dost = GreatFriend
  - Dost + düşman = Neutral
  - Nötr + dost = Friend
  - Nötr + düşman = Enemy
  - Düşman + dost = Neutral
  - Düşman + düşman = GreatEnemy
- **Yanma:** Graha ile Güneş arasındaki en kısa açı orba eşit ya da küçükse (`≤`) graha yanıktır. Güneş ve düğümler asla yanmaz.
- **Sripati:** Swiss Ephemeris'in yerleşik `'S'` sistemi kullanılır (`swehouse.c`, "uses Porphyry sectors, but then takes middle of sectors as cusps"). Lagna ve MC'den çeyrekler üçe bölünür; bulunan noktalar bhava madhya'dır. SE'nin döndürdüğü cusp'lar komşu madhyaların ortasıdır, yani bhava **başlangıcı** (sandhi). Bu, JHora'nın Sripati tanımıyla aynıdır: Porphyry üçe bölmesi madhya, aradaki orta noktalar sandhi.
- **Whole Sign:** 1. bhava lagnanın burcudur. Grahanın evi = lagna burcundan sayınca grahanın burcu.
- **Placidus:** SE `'P'`. Kutup dairesinde SE Porphyry'ye düşer; `ChartWarning::PlacidusPolarFallback` eklenir.
- **Tropikal rasi + sidereal nakshatra (`TropicalRasiSiderealNakshatra`):**
  - Tropikal boylamdan: `lon`, `sign`, `deg_in_sign`, lagna, bhava cusp'ları, ev, dignity (ve dignity'deki geçici dostluk).
  - Sidereal boylamdan (`tropikal − ayanamsa`): `sidereal_lon`, nakshatra ve pada.
  - Yanma açısal farka dayanır, iki çerçevede de aynıdır.

```rust
//! Zodyak aritmetiği: normalizasyon, burç, burç içi derece, nakshatra ve pada.

use serde::{Deserialize, Serialize};

/// Bir nakshatranın genişliği: 360° / 27 = 13°20′.
pub const NAKSHATRA_SPAN_DEG: f64 = 40.0 / 3.0;
/// Bir padanın genişliği: 360° / 108 = 3°20′.
pub const PADA_SPAN_DEG: f64 = 10.0 / 3.0;

/// [0, 360) aralığına indirger; `rem_euclid` küçük negatiflerde 360.0 verebilir.
pub fn normalize(deg: f64) -> f64 {
    let r = deg.rem_euclid(360.0);
    if r >= 360.0 {
        0.0
    } else {
        r
    }
}

/// İki boylam arasındaki en kısa yay, [0, 180].
pub fn angular_distance(a: f64, b: f64) -> f64 {
    let d = normalize(a - b);
    d.min(360.0 - d)
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)]
pub enum Sign {
    Aries,
    Taurus,
    Gemini,
    Cancer,
    Leo,
    Virgo,
    Libra,
    Scorpio,
    Sagittarius,
    Capricorn,
    Aquarius,
    Pisces,
}

impl Sign {
    pub const ALL: [Sign; 12] = [
        Sign::Aries,
        Sign::Taurus,
        Sign::Gemini,
        Sign::Cancer,
        Sign::Leo,
        Sign::Virgo,
        Sign::Libra,
        Sign::Scorpio,
        Sign::Sagittarius,
        Sign::Capricorn,
        Sign::Aquarius,
        Sign::Pisces,
    ];

    /// 12'ye göre mod alınır.
    pub fn from_index(i: usize) -> Sign {
        Self::ALL[i % 12]
    }

    /// Koç 0, Balık 11.
    pub fn index(self) -> usize {
        self as usize
    }

    /// Boylamın düştüğü burç.
    pub fn of(lon: f64) -> Sign {
        let i = (normalize(lon) / 30.0) as usize;
        Self::ALL[i.min(11)]
    }

    /// `from` burcundan sayınca bu burç kaçıncıdır: aynı burç 1, karşı burç 7.
    pub fn house_from(self, from: Sign) -> u8 {
        ((self.index() + 12 - from.index()) % 12 + 1) as u8
    }
}

/// Burç içi derece, [0, 30).
pub fn deg_in_sign(lon: f64) -> f64 {
    let l = normalize(lon);
    l - Sign::of(l).index() as f64 * 30.0
}

/// Sidereal boylamdan (nakshatra 1..=27, pada 1..=4). İkisi de aynı pada indeksinden
/// (0..108) türetilir, böylece her zaman tutarlıdır. `×3/10` çarpımı 3°20′'nin tüm
/// katlarında tam sınır verir (k·10/3 için k = 1..107 doğrulandı).
pub fn nakshatra_pada(sidereal_lon: f64) -> (u8, u8) {
    let idx = ((normalize(sidereal_lon) * 3.0 / 10.0) as usize).min(107);
    ((idx / 4 + 1) as u8, (idx % 4 + 1) as u8)
}
```

use serde::{Deserialize, Serialize};

use crate::graha::Graha;
use crate::zodiac::Sign;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Dignity {
    Exalted,
    Moolatrikona,
    OwnSign,
    GreatFriend,
    Friend,
    Neutral,
    Enemy,
    GreatEnemy,
    Debilitated,
}

/// Doğal (naisargika) ilişki.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Relation {
    Friend,
    Neutral,
    Enemy,
}

pub fn sign_lord(sign: Sign) -> Graha {
    match sign {
        Sign::Aries | Sign::Scorpio => Graha::Mars,
        Sign::Taurus | Sign::Libra => Graha::Venus,
        Sign::Gemini | Sign::Virgo => Graha::Mercury,
        Sign::Cancer => Graha::Moon,
        Sign::Leo => Graha::Sun,
        Sign::Sagittarius | Sign::Pisces => Graha::Jupiter,
        Sign::Capricorn | Sign::Aquarius => Graha::Saturn,
    }
}

/// Derin yücelme noktası (burç, burç içi derece).
pub fn exaltation_point(graha: Graha) -> Option<(Sign, f64)> {
    match graha {
        Graha::Sun => Some((Sign::Aries, 10.0)),
        Graha::Moon => Some((Sign::Taurus, 3.0)),
        Graha::Mars => Some((Sign::Capricorn, 28.0)),
        Graha::Mercury => Some((Sign::Virgo, 15.0)),
        Graha::Jupiter => Some((Sign::Cancer, 5.0)),
        Graha::Venus => Some((Sign::Pisces, 27.0)),
        Graha::Saturn => Some((Sign::Libra, 20.0)),
        Graha::Rahu | Graha::Ketu => None,
    }
}

/// Derin düşüş: yücelme noktasının tam karşısı.
pub fn debilitation_point(graha: Graha) -> Option<(Sign, f64)> {
    exaltation_point(graha).map(|(s, deg)| (Sign::from_index(s.index() + 6), deg))
}

/// Moolatrikona burcu ve `[başlangıç, bitiş)` derece aralığı.
pub fn moolatrikona(graha: Graha) -> Option<(Sign, f64, f64)> {
    match graha {
        Graha::Sun => Some((Sign::Leo, 0.0, 20.0)),
        Graha::Moon => Some((Sign::Taurus, 3.0, 30.0)),
        Graha::Mars => Some((Sign::Aries, 0.0, 12.0)),
        Graha::Mercury => Some((Sign::Virgo, 15.0, 20.0)),
        Graha::Jupiter => Some((Sign::Sagittarius, 0.0, 10.0)),
        Graha::Venus => Some((Sign::Libra, 0.0, 15.0)),
        Graha::Saturn => Some((Sign::Aquarius, 0.0, 20.0)),
        Graha::Rahu | Graha::Ketu => None,
    }
}

pub fn own_signs(graha: Graha) -> &'static [Sign] {
    match graha {
        Graha::Sun => &[Sign::Leo],
        Graha::Moon => &[Sign::Cancer],
        Graha::Mars => &[Sign::Aries, Sign::Scorpio],
        Graha::Mercury => &[Sign::Gemini, Sign::Virgo],
        Graha::Jupiter => &[Sign::Sagittarius, Sign::Pisces],
        Graha::Venus => &[Sign::Taurus, Sign::Libra],
        Graha::Saturn => &[Sign::Capricorn, Sign::Aquarius],
        Graha::Rahu | Graha::Ketu => &[],
    }
}

/// `of`'un `toward`'a doğal ilişkisi (BPHS). Kendisi ve düğümler tablo dışıdır: `Neutral`.
pub fn natural_relation(of: Graha, toward: Graha) -> Relation {
    use Graha::{Jupiter, Mars, Mercury, Moon, Saturn, Sun, Venus};
    use Relation::{Enemy, Friend, Neutral};
    match (of, toward) {
        (Sun, Moon | Mars | Jupiter) => Friend,
        (Sun, Mercury) => Neutral,
        (Sun, Venus | Saturn) => Enemy,
        (Moon, Sun | Mercury) => Friend,
        (Moon, Mars | Jupiter | Venus | Saturn) => Neutral,
        (Mars, Sun | Moon | Jupiter) => Friend,
        (Mars, Venus | Saturn) => Neutral,
        (Mars, Mercury) => Enemy,
        (Mercury, Sun | Venus) => Friend,
        (Mercury, Mars | Jupiter | Saturn) => Neutral,
        (Mercury, Moon) => Enemy,
        (Jupiter, Sun | Moon | Mars) => Friend,
        (Jupiter, Saturn) => Neutral,
        (Jupiter, Mercury | Venus) => Enemy,
        (Venus, Mercury | Saturn) => Friend,
        (Venus, Mars | Jupiter) => Neutral,
        (Venus, Sun | Moon) => Enemy,
        (Saturn, Mercury | Venus) => Friend,
        (Saturn, Jupiter) => Neutral,
        (Saturn, Sun | Moon | Mars) => Enemy,
        _ => Neutral,
    }
}

/// Geçici (tatkalika) dostluk: `toward_sign`, `of_sign`'dan sayınca 2, 3, 4, 10, 11
/// veya 12. burçtaysa dost, aksi halde düşman.
pub fn temporal_friend(of_sign: Sign, toward_sign: Sign) -> bool {
    matches!(toward_sign.house_from(of_sign), 2 | 3 | 4 | 10 | 11 | 12)
}

/// Panchadha maitri: doğal ve geçici ilişkinin birleşimi.
pub fn compound_relation(natural: Relation, temporal_friend: bool) -> Dignity {
    match (natural, temporal_friend) {
        (Relation::Friend, true) => Dignity::GreatFriend,
        (Relation::Friend, false) => Dignity::Neutral,
        (Relation::Neutral, true) => Dignity::Friend,
        (Relation::Neutral, false) => Dignity::Enemy,
        (Relation::Enemy, true) => Dignity::Neutral,
        (Relation::Enemy, false) => Dignity::GreatEnemy,
    }
}

/// `graha`'nın `sign` içinde `deg_in_sign` derecedeki dignity'si. `lord_sign`, `sign`
/// burcunun lordunun haritadaki burcudur (geçici dostluk için). Düğümler `None`.
///
/// Sıra: yücelme, düşüş, moolatrikona, kendi burcu, panchadha maitri. Ay ve Merkür'ün
/// yücelme burcu moolatrikona burcuyla aynıdır; orada yücelme yalnızca moolatrikona
/// aralığından önceki derecelerde geçerlidir (Ay Boğa 0–3°, Merkür Başak 0–15°).
pub fn dignity(graha: Graha, sign: Sign, deg_in_sign: f64, lord_sign: Sign) -> Option<Dignity> {
    let (exalt_sign, _) = exaltation_point(graha)?;
    let mt = moolatrikona(graha);
    if sign == exalt_sign {
        let exalted = match mt {
            Some((mt_sign, mt_from, _)) if mt_sign == sign => deg_in_sign < mt_from,
            _ => true,
        };
        if exalted {
            return Some(Dignity::Exalted);
        }
    }
    if sign == Sign::from_index(exalt_sign.index() + 6) {
        return Some(Dignity::Debilitated);
    }
    if let Some((mt_sign, from, to)) = mt {
        if sign == mt_sign && deg_in_sign >= from && deg_in_sign < to {
            return Some(Dignity::Moolatrikona);
        }
    }
    if own_signs(graha).contains(&sign) {
        return Some(Dignity::OwnSign);
    }
    let lord = sign_lord(sign);
    Some(compound_relation(
        natural_relation(graha, lord),
        temporal_friend(sign, lord_sign),
    ))
}

/// Sınır dahildir (`≤ orb`). Güneş ve düğümler asla yanmaz.

    graha: Graha,
    lon: f64,
    sun_lon: f64,
    retrograde: bool,
    orbs: &CombustionOrbs,

        Graha::Jupiter => orbs.jupiter,
        Graha::Venus if retrograde => orbs.venus_retro,
        Graha::Venus => orbs.venus,
        Graha::Saturn => orbs.saturn,
    };
    angular_distance(lon, sun_lon) <= orb
}

//! Lagna ve bhavalar. Bhava başlangıçları rasi çerçevesindedir (sidereal ya da tropikal).

use serde::{Deserialize, Serialize};

use crate::settings::HouseSystem;
use crate::zodiac::{deg_in_sign, nakshatra_pada, normalize, Sign};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Lagna {
    /// Rasi çerçevesinde boylam.
    pub lon: f64,
    /// Sidereal boylam; nakshatra ve pada buradan.
    pub sidereal_lon: f64,
    pub sign: Sign,
    pub deg_in_sign: f64,
    pub nakshatra: u8,
    pub pada: u8,
}

impl Lagna {
    pub fn new(lon: f64, sidereal_lon: f64) -> Lagna {
        let lon = normalize(lon);
        let sidereal_lon = normalize(sidereal_lon);
        let (nakshatra, pada) = nakshatra_pada(sidereal_lon);
        Lagna {
            lon,
            sidereal_lon,
            sign: Sign::of(lon),
            deg_in_sign: deg_in_sign(lon),
            nakshatra,
            pada,
        }
    }
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Bhavas {
    pub system: HouseSystem,
    /// İlk bhavadan başlayarak 12 bhavanın başlangıç boylamı (rasi çerçevesi).
    /// Whole Sign: burç başları. Sripati: sandhi. Placidus: cusp.
    pub cusps: Vec<f64>,
}

pub fn whole_sign_cusps(lagna_sign: Sign) -> Vec<f64> {
    (0..12)
        .map(|i| Sign::from_index(lagna_sign.index() + i).index() as f64 * 30.0)
        .collect()
}

/// Whole Sign: lagna burcundan sayınca grahanın burcu.
pub fn whole_sign_house(sign: Sign, lagna_sign: Sign) -> u8 {
    sign.house_from(lagna_sign)
}

/// Sıralı bhava başlangıçlarına göre ev, 1..=12. Boylamdan geriye en yakın başlangıç,
/// içinde bulunulan bhavanın başlangıcıdır; başlangıç noktası o bhavaya dahildir.
pub fn house_from_cusps(lon: f64, cusps: &[f64]) -> u8 {
    let mut best = 0usize;
    let mut best_d = f64::INFINITY;
    for (i, c) in cusps.iter().enumerate() {
        // normalize() değil: bir ulp altındaki boylam 360.0'a yuvarlanıp 0'a sarmamalı.
        let d = (lon - c).rem_euclid(360.0);
        if d < best_d {
            best_d = d;
            best = i;
        }
    }
    (best + 1) as u8
}

//! sidereal = tropikal − `ayanamsa`. Evler lagnadan eşit 30°'lik cusp'lardır.

use ephemeris::{
    Ayanamsa, Body, BodyPosition, EphError, Ephemeris, HouseSystem, Houses, Precision,
    SiderealMode, Zodiac,
};

use crate::zodiac::normalize;

pub(crate) struct FakeEph {
    /// (cisim, tropikal boylam, boylam hızı °/gün)
    pub positions: Vec<(Body, f64, f64)>,
    pub ayanamsa: f64,
    /// Tropikal lagna.
    pub asc: f64,
    pub precision: Precision,
    pub porphyry_fallback: bool,
    /// Son `houses` çağrısında istenen sistem.
    pub last_house_system: Option<HouseSystem>,
}

impl Default for FakeEph {
    fn default() -> Self {
        Self {
            positions: vec![
                (Body::Sun, 10.0, 0.98),
                (Body::Moon, 95.0, 13.2),
                (Body::Mercury, 20.0, 1.2),
                (Body::Venus, 40.0, 1.1),
                (Body::Mars, 200.0, 0.6),
                (Body::Jupiter, 250.0, -0.1),
                (Body::Saturn, 300.0, 0.05),
                (Body::MeanNode, 120.0, -0.053),
                (Body::TrueNode, 125.0, 0.01),
            ],
            ayanamsa: 24.0,
            asc: 70.0,
            precision: Precision::SwissEph,
            porphyry_fallback: false,
            last_house_system: None,
        }
    }
}

impl FakeEph {
    pub fn with(mut self, body: Body, lon: f64, speed: f64) -> Self {
        for p in &mut self.positions {
            if p.0 == body {
                p.1 = lon;
                p.2 = speed;
            }
        }
        self
    }

    fn in_frame(&self, tropical: f64, zodiac: Zodiac) -> f64 {
        match zodiac {
            Zodiac::Tropical => normalize(tropical),
            Zodiac::Sidereal(_) => normalize(tropical - self.ayanamsa),
        }
    }
}

impl Ephemeris for FakeEph {
    fn body(&mut self, _jd_ut: f64, body: Body, zodiac: Zodiac) -> Result<BodyPosition, EphError> {
        let &(_, lon, speed) = self
            .positions
            .iter()
            .find(|p| p.0 == body)
            .ok_or_else(|| EphError::Calc(format!("fake: no {body:?}")))?;
        Ok(BodyPosition {
            lon: self.in_frame(lon, zodiac),
            lat: 0.0,
            distance_au: 1.0,
            lon_speed: speed,
            lat_speed: 0.0,
            dist_speed: 0.0,
            precision: self.precision,
        })
    }

    fn ayanamsa(&mut self, _jd_ut: f64, _mode: SiderealMode) -> Result<Ayanamsa, EphError> {
        Ok(Ayanamsa {
            deg: self.ayanamsa,
            precision: Precision::SwissEph,
        })
    }

    fn houses(
        &mut self,
        _jd_ut: f64,
        _geo_lat: f64,
        _geo_lon: f64,
        system: HouseSystem,
        zodiac: Zodiac,
    ) -> Result<Houses, EphError> {
        self.last_house_system = Some(system);
        let asc = self.in_frame(self.asc, zodiac);
        let cusps: [f64; 12] = std::array::from_fn(|i| normalize(asc + 30.0 * i as f64));
        Ok(Houses {
            cusps,
            asc,
            mc: normalize(asc + 270.0),
            porphyry_fallback: self.porphyry_fallback,
        })
    }

    fn swe_version(&self) -> String {
        "fake-2.10".to_owned()
    }
}

//! Harita hesabı: ayanamsa, dokuz graha, lagna, bhavalar ve graha başına
//! burç, nakshatra, pada, yanma, dignity ve ev.

use ephemeris::{Body, Ephemeris, Precision, Zodiac};
use serde::{Deserialize, Serialize};

use crate::combustion::is_combust;
use crate::dignity::{dignity, sign_lord};
use crate::graha::{Graha, GrahaPosition};
use crate::houses::{house_from_cusps, whole_sign_cusps, whole_sign_house, Bhavas, Lagna};
use crate::settings::{CalcSettings, HouseSystem, ZodiacMode};
use crate::zodiac::{deg_in_sign, nakshatra_pada, normalize, Sign};
use crate::CoreError;

/// `Chart.meta.engine_version`: bu crate'in sürümü.
pub const ENGINE_VERSION: &str = env!("CARGO_PKG_VERSION");

/// Ölümcül olmayan durumlar (spec §7); arayüz kodları i18n ile çevirir.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum ChartWarning {
    /// Güneş veya Ay Moshier yedeğiyle hesaplandı (paketlenen ephemeris aralığı dışında).
    LowPrecision,
    /// Placidus kutup dairesinde hesaplanamadı; bhava başlangıçları Porphyry.
    PlacidusPolarFallback,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ChartMeta {
    pub engine_version: String,
    pub swe_version: String,
    /// Hesapta kullanılan ayarların tam kopyası.
    pub settings: CalcSettings,
    pub warnings: Vec<ChartWarning>,
}

/// M2 haritası. Vargalar, dasha, panchang ve ashtakavarga sonraki planlarda eklenir.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Chart {
    pub meta: ChartMeta,
    pub jd_ut: f64,
    pub geo_lat: f64,
    pub geo_lon: f64,
    /// Nütasyon dahil (gerçek) ayanamsa, derece.
    pub ayanamsa_deg: f64,
    pub lagna: Lagna,
    /// Her zaman 9 eleman, `Graha::ALL` sırasında.
    pub grahas: Vec<GrahaPosition>,
    pub bhavas: Bhavas,
}

const PLANETS: [(Graha, Body); 7] = [
    (Graha::Sun, Body::Sun),
    (Graha::Moon, Body::Moon),
    (Graha::Mars, Body::Mars),
    (Graha::Mercury, Body::Mercury),
    (Graha::Jupiter, Body::Jupiter),
    (Graha::Venus, Body::Venus),
    (Graha::Saturn, Body::Saturn),
];

/// Rasi çerçevesinde ham konum.
struct Raw {
    graha: Graha,
    lon: f64,
    lat: f64,
    speed: f64,
}

/// `jd_ut` anı ve (`geo_lat` kuzey +, `geo_lon` doğu +) konumu için haritayı hesaplar.
///
/// Rasi çerçevesi `settings.zodiac`'a göre seçilir: `Sidereal` kipinde ephemeris sidereal
/// sorulur, `TropicalRasiSiderealNakshatra` kipinde tropikal sorulur ve sidereal boylam
/// `tropikal − ayanamsa` ile bulunur. SE'nin sidereal hesabı da aynı çıkarmayı yapar.
pub fn compute_chart<E: Ephemeris + ?Sized>(
    eph: &mut E,
    jd_ut: f64,
    geo_lat: f64,
    geo_lon: f64,
    settings: &CalcSettings,
) -> Result<Chart, CoreError> {
    settings.validate()?;
    if !jd_ut.is_finite() {
        return Err(CoreError::InvalidJulianDay(jd_ut));
    }
    if !((-90.0..=90.0).contains(&geo_lat) && (-180.0..=180.0).contains(&geo_lon)) {
        return Err(CoreError::InvalidLocation {
            lat: geo_lat,
            lon: geo_lon,
        });
    }

    let mode = settings.ayanamsa.sidereal_mode();
    let ayanamsa = eph.ayanamsa(jd_ut, mode)?;
    let frame = match settings.zodiac {
        ZodiacMode::Sidereal => Zodiac::Sidereal(mode),
        ZodiacMode::TropicalRasiSiderealNakshatra => Zodiac::Tropical,
    };
    let to_sidereal = |frame_lon: f64| match settings.zodiac {
        ZodiacMode::Sidereal => frame_lon,
        ZodiacMode::TropicalRasiSiderealNakshatra => normalize(frame_lon - ayanamsa.deg),
    };

    let mut warnings = Vec::new();
    let mut raw = Vec::with_capacity(9);
    for (graha, body) in PLANETS {
        let p = eph.body(jd_ut, body, frame)?;
        // Hassasiyet Güneş/Ay'dan alınır (Plan 01 notu: ayanamsa bayrağı güvenilmez).
        if matches!(graha, Graha::Sun | Graha::Moon)
            && p.precision == Precision::Moshier
            && !warnings.contains(&ChartWarning::LowPrecision)
        {
            warnings.push(ChartWarning::LowPrecision);
        }
        raw.push(Raw {
            graha,
            lon: p.lon,
            lat: p.lat,
            speed: p.lon_speed,
        });
    }
    let rahu = eph.body(jd_ut, settings.node.body(), frame)?;
    raw.push(Raw {
        graha: Graha::Rahu,
        lon: rahu.lon,
        lat: rahu.lat,
        speed: rahu.lon_speed,
    });
    // Ketu tanım gereği Rahu'nun tam karşısıdır; hareketi Rahu ile aynıdır.
    raw.push(Raw {
        graha: Graha::Ketu,
        lon: normalize(rahu.lon + 180.0),
        lat: -rahu.lat,
        speed: rahu.lon_speed,
    });

    let houses = eph.houses(
        jd_ut,
        geo_lat,
        geo_lon,
        settings.house_system.ephemeris_system(),
        frame,
    )?;
    if houses.porphyry_fallback {
        warnings.push(ChartWarning::PlacidusPolarFallback);
    }
    let lagna = Lagna::new(houses.asc, to_sidereal(houses.asc));
    let cusps = match settings.house_system {
        HouseSystem::WholeSign => whole_sign_cusps(lagna.sign),
        HouseSystem::Sripati | HouseSystem::Placidus => houses.cusps.to_vec(),
    };

    let sun_lon = raw[0].lon;
    // Burç lordları her zaman ilk 7 grahadan biridir; bulunamaması mümkün değildir.
    let sign_of = |g: Graha| raw.iter().find(|r| r.graha == g).map(|r| Sign::of(r.lon));
    let grahas = raw
        .iter()
        .map(|r| {
            let sign = Sign::of(r.lon);
            let deg = deg_in_sign(r.lon);
            let sidereal_lon = to_sidereal(r.lon);
            let (nakshatra, pada) = nakshatra_pada(sidereal_lon);
            let retrograde = r.speed < 0.0;
            let lord_sign = sign_of(sign_lord(sign)).unwrap_or(sign);
            GrahaPosition {
                graha: r.graha,
                lon: r.lon,
                sidereal_lon,
                lat: r.lat,
                speed: r.speed,
                retrograde,
                sign,
                deg_in_sign: deg,
                nakshatra,
                pada,
                combust: is_combust(r.graha, r.lon, sun_lon, retrograde, &settings.combustion_orbs),
                dignity: dignity(r.graha, sign, deg, lord_sign),
                house: match settings.house_system {
                    HouseSystem::WholeSign => whole_sign_house(sign, lagna.sign),
                    HouseSystem::Sripati | HouseSystem::Placidus => house_from_cusps(r.lon, &cusps),
                },
            }
        })
        .collect();

    Ok(Chart {
        meta: ChartMeta {
            engine_version: ENGINE_VERSION.to_owned(),
            swe_version: eph.swe_version(),
            settings: settings.clone(),
            warnings,
        },
        jd_ut,
        geo_lat,
        geo_lon,
        ayanamsa_deg: ayanamsa.deg,
        lagna,
        grahas,
        bhavas: Bhavas {
            system: settings.house_system,
            cusps,
        },
    })
}

//! `tests/golden/*.json` referans haritalarını `compute_chart` ile karşılaştırır.

fn load_fixtures(dir: &Path) -> Vec<(PathBuf, Fixture)> {
    let entries = std::fs::read_dir(dir)
        .unwrap_or_else(|e| panic!("cannot read {}: {e}", dir.display()));
    let mut paths: Vec<PathBuf> = entries
        .map(|e| e.expect("dir entry").path())
        .filter(|p| p.extension().is_some_and(|x| x == "json"))
        .collect();
    paths.sort();
    paths
        .into_iter()
        .map(|p| {
            let text = std::fs::read_to_string(&p)
                .unwrap_or_else(|e| panic!("{}: {e}", p.display()));
            let f: Fixture = serde_json::from_str(&text)
                .unwrap_or_else(|e| panic!("{}: {e}", p.display()));
            (p, f)
        })
        .collect()
}

/// Tolerans dışındaysa (ya da değer NaN ise) açıklama döner.
fn out_of_tolerance(what: &str, got: f64, want: f64, tol_arcsec: f64) -> Option<String> {
    let diff = angular_distance(got, want) * 3600.0;
    if diff.is_nan() || diff > tol_arcsec {
        Some(format!(
            "{what}: got {got:.7}, want {want:.7}, diff {diff:.3}\" > {tol_arcsec}\""
        ))
    } else {
        None
    }
}

fn compare(f: &Fixture, chart: &Chart) -> Vec<String> {
    let mut errs: Vec<String> = [
        out_of_tolerance("ayanamsa", chart.ayanamsa_deg, f.expected.ayanamsa_deg, AYANAMSA_TOL_ARCSEC),
        out_of_tolerance("lagna", chart.lagna.lon, f.expected.lagna_lon, LAGNA_TOL_ARCSEC),
    ]
    .into_iter()
    .flatten()
    .collect();
    for g in Graha::ALL {
        let name = format!("{g:?}");
        let got = chart
            .grahas
            .iter()
            .find(|p| p.graha == g)
            .map_or(f64::NAN, |p| p.lon);
        match f.expected.grahas.get(&name) {
            Some(&want) => errs.extend(out_of_tolerance(&name, got, want, GRAHA_TOL_ARCSEC)),
            None => errs.push(format!("{name}: missing from fixture")),
        }
    }
    if f.expected.grahas.len() != Graha::ALL.len() {
        errs.push(format!(
            "expected.grahas has {} keys, want exactly {:?}",
            f.expected.grahas.len(),
            Graha::ALL
        ));
    }
    errs
}

#[test]
fn tolerance_check_flags_out_of_range_nan_and_wraps() {
    let arcsec = 1.0 / 3600.0;
    assert!(out_of_tolerance("x", 10.0, 10.0 + 1.9 * arcsec, 2.0).is_none());
    assert!(out_of_tolerance("x", 10.0, 10.0 + 2.1 * arcsec, 2.0).is_some());
    assert!(out_of_tolerance("x", f64::NAN, 10.0, 2.0).is_some());
    assert!(out_of_tolerance("x", 359.9999, 0.0001, 1.0).is_none()); // 0.72″
}

//! Komut gövdesini gerçek `Engine` aktörüyle uçtan uca dener.
//! Tek test: süreçte yalnızca bir SE örneği açılabilir.

use std::path::PathBuf;

use ephemeris::{Engine, SwissEph};
use jyotish_core::{CalcSettings, Graha};
use jyotish_desk_lib::commands::compute_chart_blocking;

#[test]
fn compute_chart_runs_on_the_engine_thread_and_maps_errors() {
    let dir = PathBuf::from(env!("CARGO_MANIFEST_DIR")).join("../../data/ephe");
    let engine = Engine::spawn(dir).expect("spawn engine");

    // tests/golden/new-delhi-2000-01-01.json (swetest 2.10.03).
    let chart = compute_chart_blocking(&engine, 2_451_545.0, 28.6139, 77.2090, CalcSettings::default())
        .expect("chart");
    assert_eq!(chart.grahas.len(), 9);
    let sun = chart.grahas.iter().find(|p| p.graha == Graha::Sun).unwrap();
    assert!((sun.lon - 256.5156960).abs() * 3600.0 <= 2.0, "sun {}", sun.lon);
    assert!((chart.lagna.lon - 76.3380905).abs() * 3600.0 <= 5.0, "lagna {}", chart.lagna.lon);
    assert_eq!(chart.meta.swe_version, SwissEph::version());
    assert_eq!(chart.meta.settings, CalcSettings::default());
    assert!(chart.meta.warnings.is_empty());

    let err = compute_chart_blocking(&engine, 2_451_545.0, 91.0, 0.0, CalcSettings::default())
        .unwrap_err();
    assert_eq!(err.code, "invalid_location");
    assert_eq!(err.params["lat"], "91");

    let old = CalcSettings {
        schema_version: 2,
        ..CalcSettings::default()
    };
    let err = compute_chart_blocking(&engine, 2_451_545.0, 0.0, 0.0, old).unwrap_err();
    assert_eq!(err.code, "unsupported_schema_version");
    assert_eq!(err.params["found"], "2");
}
```

impl From<CoreError> for CommandError {
    fn from(e: CoreError) -> Self {
        match e {
            CoreError::Ephemeris(e) => e.into(),
            CoreError::UnsupportedSchemaVersion { found, supported } => Self::new(
                "unsupported_schema_version",
                &[("found", found.to_string()), ("supported", supported.to_string())],
            ),
            CoreError::InvalidSettings(field) => {
                Self::new("invalid_settings", &[("field", field.to_owned())])
            }
            CoreError::InvalidLocation { lat, lon } => Self::new(
                "invalid_location",
                &[("lat", lat.to_string()), ("lon", lon.to_string())],
            ),
            CoreError::InvalidJulianDay(jd) => {
                Self::new("invalid_julian_day", &[("jd", jd.to_string())])
            }
        }
    }
}

/// `compute_chart` komutunun gövdesi: hesap motor iş parçacığında yapılır, burada iş
/// mantığı yoktur. Bloklar; async bağlamdan `spawn_blocking` içinde çağrılmalıdır.
pub fn compute_chart_blocking(
    engine: &Engine,
    jd_ut: f64,
    lat: f64,
    lon: f64,
    settings: CalcSettings,
) -> Result<Chart, CommandError> {
    let chart = engine.call(move |se: &mut SwissEph| {
        jyotish_core::compute_chart(se, jd_ut, lat, lon, &settings)
    })??;
    Ok(chart)
}

/// Haritayı hesaplar. `jd_ut` ve konum atlas katmanında çözülmüş olarak gelir.
#[tauri::command]
#[specta::specta]
pub async fn compute_chart(
    engine: State<'_, Arc<Engine>>,
    jd_ut: f64,
    lat: f64,
    lon: f64,
    settings: CalcSettings,
) -> Result<Chart, CommandError> {
    let engine = Arc::clone(&engine);
    tauri::async_runtime::spawn_blocking(move || {
        compute_chart_blocking(&engine, jd_ut, lat, lon, settings)
    })
    .await
    .map_err(|e| CommandError::new("engine_stopped", &[("detail", e.to_string())]))?
}
```
